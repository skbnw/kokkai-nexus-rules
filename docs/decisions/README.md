# docs/decisions — ADR（意思決定記録）

`COMMON_RULES.md` §0-3 に基づく意思決定記録の置き場。

## 起票が必要な場合

- `COMMON_RULES.md` §1（不変原則）を変更するとき（**MUST**）
- 規約に反する実装が必要と判断したとき（実装せず、まず ADR を提案する。`CLAUDE_CORE.md`）
- `event_type` / evidence 種別の追加（§5-8 の統一登録簿に触れるため）

## 書式

```
ADR-NNNN-<kebab-case-slug>.md
```

必須の記載項目（§0-3）: **変更理由 / 却下した代替案 / 影響範囲**。
本リポジトリではこれに **状態・決定・検証方法** を加えた構成を標準とする。
